# Third-party components

This repository contains only the project's own code. None of the components below is included: you obtain each one
from its official source and accept its terms. Versions are the ones the project was developed and tested with.
This is a summary of what each publisher states, not legal advice; read the linked terms before you deploy.

**Restrictions to know about**

- **Paid**: Runtime MetaHuman Lip Sync and Runtime Audio Importer (Fab). Unreal Engine is free below a revenue
  threshold.
- **Non-commercial terms**: the dlib 68-point landmark model (its training data excludes commercial products; the
  project's default code path does not use it, but `face_recognition` loads it) and the HSEmotion facial-expression
  weights (trained on AffectNet, whose agreement allows non-commercial research and education only).
- **Unclear license**: emotion2vec+ (Hugging Face points to the FunASR model license, which requires attribution;
  ModelScope lists Apache 2.0).
- **Watermark**: audio generated by Chatterbox carries Resemble AI's imperceptible Perth watermark.
- **Bundled libraries**: some wheels include FFmpeg (LGPL / GPL encoders) and NVIDIA CUDA libraries under their own
  licenses.
